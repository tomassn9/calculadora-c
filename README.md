# Calculadora de Escritorio en C (GTK+ 3)

Aplicación de escritorio con interfaz gráfica desarrollada en estándar C11 utilizando la biblioteca GTK+ 3 (`libgtk-3-dev`) y compilada con `gcc`.

## Instalación de dependencias (Ubuntu / WSL)

```bash
sudo apt update
sudo apt install -y build-essential gcc make git libgtk-3-dev
